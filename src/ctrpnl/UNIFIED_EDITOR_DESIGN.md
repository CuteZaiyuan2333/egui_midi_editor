# Unified Editor (uniedt) 设计文档

## 核心理念

使用一个统一的编辑器 `Uniedt` 来实现所有功能模块。通过注入不同的绘制函数和配置参数，让同一个编辑器内核能够呈现不同的视图模式。

## 架构设计

│  │  - 轨道提示    │ │  - MIDI音符块                   │   │
│  │  - 钢琴黑白键  │ │  - 波形显示                     │   │
│  │  - 采样列表   │ │  - 轨道剪辑                     │   │
│  │               │ │                                 │   │

│                         ▲                               │
│                         │                               │
│              ┌──────────┴──────────┐                    │
│              │   API 注入机制      │                    │
│              │  - 轨道数据         │                    │

## API 设计

```rust
pub struct UniedtConfig {
    // 轨道数据
    pub tracks: Vec<Track>,

    // 提示面板配置
    pub hint_panel: HintPanelConfig,

    // Block渲染配置
    pub block_config: BlockConfig,

    // 视图模式
    pub view_mode: ViewMode,
}

pub enum ViewMode {
    PianoRoll,      // 钢琴卷帘
    SampleRoll,     // 采样编辑器
    Track,          // 轨道编辑器
    WaveInspector,  // 波形检查器
    BlueprintEditor,// 蓝图编辑器
}

pub struct HintPanelConfig {
    pub width: f32,
    pub draw_fn: fn(&mut Ui, &Track, &HintPanelConfig),
}

pub struct BlockConfig {
    pub draw_fn: fn(&mut Ui, &mut Block, &BlockConfig),
}
```

## 各视图模式具体实现

### 1. 钢琴卷帘 (Piano Roll)

```
┌────────────────────────────────────────────────────────┐
│ Hint Panel │           Block Area                      │
├────────────┼───────────────────────────────────────────┤
│            │  ┌────┐  ┌──────┐  ┌────┐                │
│  Piano     │  │Note│  │ Note │  │Note│   (音符块)       │
│  Keys      │  └────┘  └──────┘  └────┘                │
│  (88键)    │                                          │
│            │                                          │
│  C8 (白)   │                                          │
│  B7 (黑)   │                                          │
│  A#7 (黑)  │                                          │
│  A7  (白)  │                                          │
│  ...       │                                          │
│            │                                          │
│  A0  (白)  │                                          │
└────────────┴──────────────────────────────────────────┘
```

**提示面板**：绘制88个钢琴黑白键
- 白键：C音（自然音）
- 黑键：C#/D#/F#/G#/A#
- 当前选中音高高亮显示

**Block绘制**：
- 音符起始位置
- 音符时长（宽度）
- 音高（垂直位置，对应钢琴键）
- 颜色区分不同velocity

**提示面板**：轨道功能按钮

**Block绘制**：

- MIDI事件略缩图（简化显示音符分布）
- 轨道高度可调
- 选中/悬停状态

## 交互设计

### 通用交互
- **缩放**：Ctrl + 滚轮 / 缩放滑块
- **滚动**：滚轮 / 拖拽空白区域
- **选择**：点击选中，Shift+点击多选
- **框选**：拖拽创建选择框

### Piano Roll 专用
- **添加音符**：双击空白区域
- **移动音符**：拖拽音符块
- **调整时长**：拖拽音符块边缘
- **调整力度**：拖拽音符块上下

### Sample Roll 专用
- **添加采样**：从文件浏览器拖拽
- **调整循环**：拖拽循环标记点
- **预览**：点击采样块播放

### Track Editor 专用
- **添加剪辑**：从浏览器拖拽
- **移动剪辑**：拖拽
- **分割剪辑**：Ctrl+E
- **合并剪辑**：选中多个 + Ctrl+M

## 优势

1. **代码复用**：统一的编辑器核心，所有视图模式共享
2. **可扩展性**：新增视图模式只需实现新的绘制函数
3. **一致性**：所有编辑器视图保持相同的交互体验
4. **解耦**：编辑器逻辑与UI渲染分离
5. **灵活性**：用户可自定义提示面板和绘制逻辑
